# PIPELINE-MAP — nofx trading machine, stage by stage

Owner reference for the full decision path. Every arrow is a named wire; every
gate is listed in its real execution order. Generated by the research
conformance audit (2026-08-22), branch `audit/research-conformance`. If you
change a stage, update this file in the same PR.

**As-built at the 1h-wave cutover rev (see `deploy/RELEASE`)** — updated
2026-08-25 for the 1h wave, the W6 wake semantics, the G6 removal, and the
R2/R4 grading gates.

## Legend

- **Producer → Consumer** arrows name the data structure/function that carries the data.
- Gates that can BLOCK an entry are marked 🚫; advisory-only stages are marked ℹ️.

## Stage 1 — Data ingress

```
NT8 (Tradovate real-time MNQ bars)
  └─ VL C# AddOn (AddOns folder; NO hot-reload, full NT8 restart required)
       └─ TCP frames (length-prefixed JSON; spec: ninjascript/vltrader_tcp_PROTOCOL.md)
            └─ provider/ninjatrader (Go TCP reader, reconnect + watchdog)
                 ├─ bars      → market.BarCache (key "MNQ", per-TF series)
                 ├─ account   → trader account state (equity/balance)
                 └─ positions/orders → trader position store mirror
```

- **Stamp contract**: bars carry OpenTime; a bar is CLOSED iff `CloseTime =
  OpenTime + interval` is ≤ now (repo convention — CloseTime is the last instant
  INSIDE the bar). The forming bar is the one whose close is still in the
  future.
- **The single source of truth**: everything below reads `market.FuturesBarsProvider(symbol, tf, count)` → BarCache. No stage fetches its own bars.

## Stage 2 — Level detectors → grading

```
BarCache (1m + per-TF)
  └─ kernel.AssembleScoredLevels (kernel/levels_assemble.go)
       ├─ 9 detectors: PDH/PDL/PDC (RTH session boundaries, CT),
       │   ON H/L (Asia+London composite), OR/IB durations, EQH/EQL
       │   (equality tolerance), round numbers, gaps, S/D zones, FVG (3-bar),
       │   OB selection, nPOC (session volume profile)
       ├─ dATR = DailyATRProxy (daily ATR estimate from intraday bars)
       ├─ activation window: |level − price| ≤ 1.5 × dATR (DAY-TRADE LOCK)
       └─ grading: type evidence × freshness × confluence × HTF origin → A/B/C
            (Go-deterministic; the LLM never sorts)
```

## Stage 3 — Planner (reasoner)

```
Kernel session registry (system_config, CT-anchored rows)
  └─ trader/auto_trader_planner.go maybeRunSessionReadsAt — wake-ups:
       1. session first read (read window, once per session-day)
       2. re-plan on death (structured death/flip, G7 freshness-gated)
       3. owner reread / reset
       4. G4.6 structure_mss — fresh MSS on the plan's bias TF (15m),
          one wake per event (dedupe: plan version + event instant)
       5. W6 (2026-08-25) — level-event wakes (15m zones, HTF zones, seated
          invalidation, iFVG inversions, HTF OBs): UNLIMITED and BUDGET-FREE
          (W6-D: only DEATHS consume replan_cap), async + non-fatal
          (W6-C: a failed wake read keeps the active plan), throttled by
          wake_min_interval_min (default 30)
       ↓
  planner input: levels + regime + digests + consumed levels (G5) +
  structure lines (G2) + indicator mirror + owner note +
  HTF zones section (G2.2 — nearest-first, cap 4; 1h wave guarantees a 1h
  S/D row when one is in band, seat_1h_zone knob default ON) + conditional
  1h S/D MUST-include mandate (emitted only when rendered)
       ↓
  kernel.BuildPlannerPrompt → planner model call (≤2 retries, then
  FAIL-CLOSED NO-TRADE plan)
       ↓
  ParsePlanDocCapped → ValidatePlanDocWithFacts (both-side levels,
  continuation scenarios, reachable targets) → G5 demotion of consumed
  triggers (quality cap C + badge)
       ↓
  plans table (append-only; key trade_date+session+version; trigger_reason
  column carries the wake-up that wrote it)
```

## Stage 4 — Card render

```
plans + plan_overlays + level_state + system_config
  └─ api/handler_plan.go → plan card JSON
       ├─ levels with live facts (distance/sweep/closes-beyond/acceptance/valid)
       ├─ scenario status ○ ◉ ● ✕ (system_config scenario_status)
```

## Stage 5 — Executor cycle (the decision path)

```
runCycle (trader/auto_trader_loop.go)
  ├─ session gate (CME open) → multi-account gate → dead-man watchdog
  ├─ planner reads (Stage 3) + digests + level state writers
  ├─ dodge: defer a cycle starting within avg_call_ms×1.2 of a bar close
  ├─ buildTradingContext → ctx (prompt-ownership tags asserted)
  ├─ ONE-SNAPSHOT contract: snapshotNow + 1m bars captured together;
  │   everything in the prompt derives from that instant
  ├─ G2 structure snapshot: kernel.StructureSnapshot(1m cache → 5m/15m/1h)
  │   → ctx.Structure → persisted decision_records.structure_json
  ├─ G1 inputs: ctx.HTFVetoEnabled (Studio regime.htf_veto, nil→ON) +
  │   ctx.HTFVetoTF (env HTF_VETO_TF, default 1h)
  ├─ G4 state machine: observeTransitionStanddown(ctx) — CHoCH/MSS on the
  │   plan's bias TF (15m) opens TRANSITION; flip/re-plan, BOS resumption or
  │   TRANSITION_MAX_MIN (45) closes it → ctx.Transition*
  ↓
  system prompt (clock line → instrument → plan block → PLAN STATUS) +
  user prompt (market tables per TF, forming/closed labels, G7 staleness
  labels, G2 STRUCTURE line)
  ↓
  AI call (callWithSchemaRetry ≤2) → parseFullDecisionResponse →
  validateDecisions → validateDecision — THE GATE CHAIN, in order:
       1. action enum + leverage/size sanity
       2. SL/TP sanity (B2 price armor upstream)
       3. F1 real R:R from the actual entry reference (entry = snapshot price,
          AI limit wins) vs min_risk_reward_ratio (default 3.0, floor 1.0)
       4. min-confidence (SafeDefaultMinConfidence=60; config wins)
       5. 🚫 G1 HTF VETO — opposed vs CONFIRMED 1h structure refused
          ("htf_veto: short vs 1h TRENDING_UP (BOS …)"), RANGING/unavailable
          fail-open WARN
       6. 🚫 G4 TRANSITION STAND-DOWN — plan-direction entries paused while an
          unconfirmed counter-trend CHoCH/MSS is open; counter-direction
          untouched
       7. 🚫 C6 EXECUTOR DEAD-PLAN GATE — the machine-dead plan verdict blocks
          new entries (management proceeds)
       8. 🚫 R4 MIN-SCENARIO-QUALITY (2026-08-25) — min_scenario_quality floor
          (A|B; default C = no restriction): an entry citing a scenario graded
          below the floor is refused; fail-open on off-plan/unknown citations
       9. sizing caps (futures notional ceiling + per-order clamp)
  ↓
  executeDecisionWithRecord → NT8 SIM order via the same TCP AddOn → ACK →
  fill → position row (frozen plan_id/version/scenario at entry)
```

## Stage 6 — In-position

```
POSITION OPEN
  ├─ 👁 WATCHER (runWatchCycle, zero order authority):
  │     observer system prompt = thesis verbatim + machine STRUCTURE line +
  │     TWO questions (thesis_status; structure_conflict none|warning|confirmed)
  │     → rails R1/R2 hysteresis (min-conf 70, min-hold 2, warn-consec 2) →
  │     watch_assessments row (thesis + structure_conflict after 2-consecutive
  │     hysteresis) → watch_json on the decision row → 👁 badge + structure dot
  │     (green/amber/red). WARN only when thesis invalidated AND
  │     structure confirmed-conflict — still nothing emitted.
  └─ 60s monitor (auto_trader_risk.go): feed-down watch → clock health →
      dead-man → BE trigger → trailing chandelier (5m ATR) → EOD flat
```

## Stage 7 — Exit → post-exit

```
close (NT8 OCO SL/TP, EOD flat, or AI close) → ClosePosition
  ├─ PnL write: realized_pnl from stored prices; pnl_corrected layer
  │   (additive corrections, never edits) — every reader uses
  │   EffectivePnL / COALESCE
  ├─ per-close integrity guard: recompute vs stored, delta > $0.50 → WARN +
  │   counter (class-killer)
  ├─ post-exit rescan kick (cycle_trigger=post_exit, same gates)
  ├─ learning loop: grade ungraded closes, adherence, watch backfill
  └─ digests (session 3-line, daily rollup) + gate-block counters roll at the
      CME session-day boundary (17:00 CT)
```

## Cross-cutting wires (named)

| Wire | Producer | Consumers |
|---|---|---|
| `market.FuturesBarsProvider` | NT8 BarCache | detectors, planner, executor prompt, watcher, structure, level facts |
| `decision_records.structure_json` | runCycle (G2 snapshot) | forensics/replay; G1/G4/G8 read the live `ctx.Structure` in-cycle |
| `ctx.Structure` | runCycle | executor STRUCTURE prompt line, G1 veto, G4 state machine, G8 watcher line |
| `plans.trigger_reason` | planner wake-up | plan card ("why this version was written") |
| `system_config transition:<plan>:<v>` | G4 state machine | plan card chip |
| `day_plan_alerts` (P0/P1/P2, event-id dedupe) | every gate/guard | bell + persistent P0 banner until ack |
| `log_events` | WARN-class events | forensics |
| `telemetry gate-block counters` | each gate | /api/risk/gate-blocks |

## Advisory-only layers (never gates)

- G2 STRUCTURE prompt line (machine truth, AI judges)
- G5 consumed-level demotion + planner list
- G7 flip-eval freshness (skips the transition EVALUATION on stale bars — a
  correctness veto on state transitions, not an entry gate)
- G8 watcher hooks (zero order authority)
