# D1 — W2 A1–A5 + W3 entry-policy/zone replay over plans since 09-17

READ-ONLY replay of the W-EXEC-TRUTH W2 write-time contract (A1–A5) and the W3
entry-policy/zone checks against every stored plan since 2026-09-17. Every
predicate is a production call site, run by `cmd/w2w3_replay` (in the same PR)
over an NDJSON export from `sqlite3 -readonly` (`nice -n 19`). 73 rows
(rowids 397–470, `WHERE created_at >= '2026-09-17'`).

**Method, and what is NOT replayed (never fabricated):**

- A1 — `kernel.EvaluateAuthoredInvalidationAt(sc, nil, zero)`: with a nil tape
  the verdict is `AuthoredUnknownGrammar` exactly when the sentence is outside
  the grammar (the tape is never consulted on that path).
- A2 — `kernel.AuthoredBornGroups(read, publish)`: the closed-5m-group count
  between the row's stored read/publish clocks. **The breach judgment needs
  minute bars, which the plan row does not carry — UNREPLAYED, stated per row.**
- A3/A4 — `kernel.CheckScenarioWriteTruth(d, seated, nil, 0.25)`, with `seated`
  rebuilt from the doc's STORED `identity_levels` (the write site froze that
  projection into the doc). `capacityCut = nil` (the dropped seat race is not
  stored — a first obstacle that only the cut can name reads missing). A3
  resolves against the stored projection, which is what the doc carries.
- A5 — `kernel.ResolveConfirm`: a time_hold resolving from the env authoring
  default is the missing-stored-duration refusal. Rows 450/452 are the SAME
  rule firing at parse time (the parser refuses the prose-stated hold with no
  stored hold_min).
- W3 — `kernel.EffectiveArmPolicy` / `ArmableConditionFor` / `ArmZoneVerdict`
  over the stored arms and legs; zone width cap = 0 (uncapped — the cap needs a
  strategy config this replay does not have). Legacy arms are never judged (the
  policy branch only runs when a policy is named — byte-identical pre-W3).

## Findings

1. **A1 is the dominant write-time refusal by far**: 50 of 73 plans (68%) carry
   at least one `invalid` sentence outside the grammar, 106 scenarios total.
   Under the W2 contract every one of those scenarios would have been REFUSED at
   write, not accepted as UNKNOWN. Row 455 (the wave's own evidence row) is on
   the list, as expected [A].
2. **A4 path_level_missing fires on 82 scenarios across 47 plans** — most stored
   plans omit seated path levels the contract now requires. obstacle_not_nearest
   (52) and reduce_qty1 (25) are the second and third largest A4 classes.
3. **A2 only touches the five newest rows (466–470)**: read/publish clocks are
   absent (0) on every earlier row — the legacy latest-window check would have
   run there, and the breach half of A2 cannot be replayed from the row alone.
4. **W3 has engaged zero times since 09-17**: none of the 73 stored docs carries
   a policy-stamped arm (`"policy"` absent everywhere; `entry_policy_default`
   resolves to legacy and legacy stamps nothing). The zone checks would have
   refused nothing — there was nothing policy-bearing to judge.
5. A5 fires on 4 plans; two of them (450, 452) are refused at PARSE time today,
   the other two (426, 455) only at the resolver.

Row 402/403 flip↔bias and row 419 unmarshal failures are pre-W2 parser refusals
and are reported separately, not attributed to A1–A5.
