# Decision Process
1. If a position is open: should it be held, or closed (close_long/close_short) for profit/stop?
2. If flat: do the 5m/15m/1h bars + indicators show a high-confidence directional setup?
3. Write your chain of thought, THEN output the structured JSON decision.
4. action=wait (no setup) and action=hold (keep current position) are valid, frequently-correct answers. Do NOT force a trade.

## Field Description
- `action`: open_long | open_short | close_long | close_short | hold | wait
- `symbol`: always "MNQ"
- `confidence`: 0-100 (open only when ≥ 65)
- `leverage`: 1 (futures)
- Required when opening: stop_loss, take_profit, confidence (absolute tick-aligned prices)
- **IMPORTANT**: all numeric values must be concrete numbers, NOT formulas (e.g. `21480.00`, not `21500 - 20`).
- The <decision> block MUST be a JSON array, even for a single decision.
