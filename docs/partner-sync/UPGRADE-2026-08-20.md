## 1. What's new (grouped)

**Decision-cycle quality**
- **Stale dodge** (`STALE_DODGE`, on by default): a cycle that would span a 5m
  bar close now defers to close+1s instead of burning an AI call on a dying
  bar; superseded entries are re-evaluated against the fresh bar, and
  superseded *waits* are quietly discarded (was ~18% of paid calls).
- **Stale-guard v2** and one shared timeframe table (1m/5m/15m/3m/30m with
  correct interval math; an unmapped primary timeframe is now a boot FAIL
  instead of a silent 60s fabrication).
- **Post-exit rescan** (`POST_EXIT_RESCAN`, on by default): the moment a
  position closes, one fresh decision cycle fires (all gates still apply).
- **402 handling**: an AI-credit 402 becomes one P0 "AI CREDIT EXHAUSTED"
  banner instead of 139 log lines; clears on first success; optional daily
  DeepSeek balance poll.
- **AI timeout chain**: planner calls get a 320s budget; a thrown timeout can
  no longer latch UI buttons or silently lose your input.

**In-position safety**
- **Watcher (ai_watch, the new default)**: while a position is open, the AI
  watches its own thesis each cycle with a schema-checked assessment
  (`watch_assessments` scoring table, 👁 dashboard rows). It has **zero order
  authority** — it can only flag. Hysteresis rails: min-conf 70, one-step
  downgrade, 2 consecutive WARNs before anything surfaces. **To keep your old
  behavior (no in-position AI): set the trader's `position_mode` to
  `bracket_only`** in Studio or DB.
- **Trailing profit** (Risk Control, **OFF by default**): best-price ∓
  ATR-multiple ratchet on the existing move-stop path; arms after-breakeven /
  points / immediate; never moves against you.
- **In-position heartbeats**: dashboards/equity keep updating while holding
  (previously froze); phantom-position/desync guard reconciles against live
  NT8 truth and logs CRITICAL on desync instead of trusting a stale row.

**Session rules & calendar**
- Per-session entry cutoffs (last-entry + EOD-flat, CT-anchored) with fixes
  for Asia-evening entries and the 14:45-flatten twin.
- **Contract-roll block**: final `ROLL_BLOCK_DAYS_BEFORE_EXPIRY` days before
  the front contract expires, entries are gated (fail-open if unresolved).
- **Half-days**: official 2026 CME early-close table (Labor Day 12:00 CT
  etc.) shortens last-entry/EOD-flat on those days.
- **Pause button** (`stop_until`): one-tap pause for NEW entries only —
  closes, EOD-flat and brackets continue; auto-resumes on expiry; survives
  restart.
- **Clock guard + boot integrity**: a user timer measures host-vs-WSL drift
  every 15 min; boot prints a ten-item ledger (sessions, cadence, roll
  status, half-days, clock health…) and asserts the running binary matches
  `deploy/RELEASE` when that file is filled in.

**Day-plan suite (the big one)**
- Append-only `plans` / `plan_overlays`, session registry, level-state table,
  the scenario evaluator, session timeline + plan card UI, in-app alert
  center, planner advisory mode. Planner output now has a **structured
  confirm{} grammar** (confirm rule + ref price + side) with a
  **3-session grace window** before old-shape plans are refused.
- **Cite required**: advisory lines must cite `scenario_id` + match-rate.
- Day-plan is advisory-only by default; the owner's manual Re-read / reset
  tools are included.

**Honest data**
- **PnL integrity**: a manual NT8 flatten's qty can no longer be attributed
  to the bot's row (quantity-attribution fix); every close now re-verifies
  recorded vs recomputed PnL and WARNs to `log_events` on a delta > $0.50;
  an additive correction layer (`pnl_corrected` + `note`) repaired the wrong
  rows without editing originals.
- **log_events shipping**: WARN+ERROR log lines now land in a `log_events`
  table (survives journald rotation) with daily retention.
- **Entry-confidence backfill**: one-time, flag-guarded recovery of
  historical entry confidences (feeds the watcher's history).
- **min_confidence default = 60 everywhere** (gate and prompt agree now).

**UI & wire**
- Frozen-button sweep: reset/reread/realign/edit-sheet/ask-planner/plan-door
  all go through a never-latch guarded call; save honesty (toast only on
  HTTP 200).
- Chart stamps: one CT label site (charts matched NT8), NT8 close-stamps
  converted to OPEN stamps once at ingest, empty-minute placeholders refused.
- Trader selection persists; active-trader marker; cadence mode selector;
  Strategy Studio readability pass.

## 2. BREAKING / ACTION REQUIRED

### 2.1 Database migrations

**You do not need to run these by hand.** gorm `AutoMigrate` performs all of
them additively and idempotently at first boot after the upgrade. They are
listed here so you can review/back up first. (Backup: copy `data.db` before
restart — see §0.)

```sql
-- traders
ALTER TABLE traders ADD COLUMN position_mode TEXT NOT NULL DEFAULT '';  -- '' = ai_watch default
ALTER TABLE traders ADD COLUMN cadence_mode  TEXT NOT NULL DEFAULT '';  -- '' = interval
ALTER TABLE traders ADD COLUMN stop_until    TEXT NOT NULL DEFAULT '';  -- pause deadline (empty = no pause)

-- decision_records
ALTER TABLE decision_records ADD COLUMN cycle_type    TEXT NOT NULL DEFAULT '';  -- '' | watch
ALTER TABLE decision_records ADD COLUMN cycle_trigger TEXT NOT NULL DEFAULT '';  -- '' | stale_dodge | post_exit
ALTER TABLE decision_records ADD COLUMN watch_json    TEXT NOT NULL DEFAULT '';  -- observer assessment JSON

-- trader_positions (PnL integrity)
ALTER TABLE trader_positions ADD COLUMN pnl_corrected REAL;            -- NULL = no correction; readers use COALESCE
ALTER TABLE trader_positions ADD COLUMN note          TEXT NOT NULL DEFAULT '';

-- log_events (honest logs)
CREATE TABLE IF NOT EXISTS log_events (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  ts_utc      INTEGER NOT NULL,
  level       TEXT NOT NULL DEFAULT '',
  component   TEXT NOT NULL DEFAULT '',
  trader_id   TEXT NOT NULL DEFAULT '',
  message     TEXT NOT NULL DEFAULT '',
  fields_json TEXT NOT NULL DEFAULT '{}');
CREATE INDEX IF NOT EXISTS idx_log_events_ts     ON log_events(ts_utc);
CREATE INDEX IF NOT EXISTS idx_log_events_trader ON log_events(trader_id);

-- watch_assessments (watcher scoring)
CREATE TABLE IF NOT EXISTS watch_assessments (
  id                 INTEGER PRIMARY KEY AUTOINCREMENT,
  trader_id          TEXT NOT NULL,
  position_id        INTEGER NOT NULL,
  cycle_number       INTEGER NOT NULL,
  timestamp          INTEGER NOT NULL,
  status             TEXT DEFAULT '',
  accepted_status    TEXT DEFAULT '',
  confidence         INTEGER DEFAULT 0,
  invalidation_cited TEXT DEFAULT '',
  note               TEXT DEFAULT '',
  price_at_read      REAL DEFAULT 0,
  warned             BOOLEAN DEFAULT FALSE,
  mfe_after_pts      REAL DEFAULT 0,
  mae_after_pts      REAL DEFAULT 0,
  final_outcome      TEXT DEFAULT '');
CREATE INDEX IF NOT EXISTS idx_watch_trader_pos ON watch_assessments(trader_id, position_id);
```

Day-plan tables (`plans`, `plan_overlays`, `level_state`, `session_profiles`,
`day_plan_digests`, `day_plan_alerts`, calendar slices) are likewise created
by AutoMigrate — no manual SQL. The entry-confidence backfill runs
automatically once at first boot (flag-guarded; it will print a
`backfill complete: N recovered` line).

### 2.4 Behavior changes on upgrade (read this twice)

1. **ai_watch becomes the default in-position mode.** While holding, the bot
   now spends one AI call per cycle watching the thesis. Cost you did not
   have before. To keep the old behavior, set the trader's `position_mode` to
   `bracket_only`.
2. **confirm{} grammar**: planner scenarios must carry a structured confirm
   (`rule: touch|1x5m_close|2x5m_close|15m_close`, ref price, side). There
   is a **3-session grace** (`CONFIRM_GRACE_SESSIONS`) during which old-shape
   output is still accepted while compliance fast-forwards.
3. **bar-close cadence**: the Studio scan interval is the decision cadence in
   interval mode; bar-close mode is now per-trader. In bar-close mode a
   decision fires on **one close** (each completed 5m bar), not every tick.
4. **cite required**: advisory plan lines must cite `scenario_id` +
   match-rate in the output contract.
5. **min_confidence default is now 60** (gate and prompt agree). Strategies
   that never set an explicit value are judged at 60 — if you rely on 65,
   set the value explicitly in Studio.
6. **Superseded waits are quietly discarded** (ℹ️ badge, not a failure).
7. **post-exit rescan on**: one extra cycle fires immediately after each
   close. Turn off with `POST_EXIT_RESCAN=off` if you don't want it.
8. **402 = outage banner**, not log spam.
9. **Boot integrity**: if `deploy/RELEASE` contains a revision, boot refuses
   to trade on a stale binary and prints `🔐 BOOT INTEGRITY OK/FAIL`. Leave
   the file empty and the check stays inert.
10. **SIM-only remains hard** — nothing in this bundle relaxes the
    live-account blocks your fork already has (LFE can still never be a
    submit target).

### 2.5 Deploy order (do it in this order)

```bash

# 3. restart the bot service (kill -9; systemd Restart=on-failure relaunches)
```

Then watch the boot log for:
- `🔐 BOOT INTEGRITY OK — rev <your rev> +dirty · built … · goldens PASS`
- the ten-item ledger line (`sessions[ASIA … LONDON … NY …] · stop_until=none ·
  cadence=interval · position_mode=ai_watch (source: default) · watcher[…] ·
  trailing=OFF · stale_dodge=on … · roll=… · balance-alert=off`)
- `half-days [boot]: 4 loaded · next: 2026-09-07 12:00 CT (Labor Day)`
- `🧮 entry_confidence backfill complete: N recovered` (first boot only)
- the normal auto-start line for your trader.

If boot prints `BOOT INTEGRITY FAIL`, you are running a binary that doesn't
match `deploy/RELEASE` — rebuild and restamp, or empty the file.
